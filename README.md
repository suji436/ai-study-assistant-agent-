# AI Study Assistant Agent

An AI-powered study assistant that explains topics in simple language and generates practice quiz questions.

## Features
- Beginner-friendly topic explanations
- Key study notes
- Real-world examples
- Multiple-choice quiz questions

## Requirements
- Python
- Gemini API key

## Run the project
1. Install the package:

   `pip install google-genai`

2. Set your Gemini API key in the terminal:

   `export GEMINI_API_KEY="YOUR_API_KEY"`

3. Run the agent:

   `python agent.py`

4. Enter a topic when prompted.
